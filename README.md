AI Resume Analyzer

An AI-powered web application that analyzes resumes against job descriptions and helps job seekers improve their applications.

Features

- Upload resumes in PDF or DOCX format.
- Compare resume skills with job requirements.
- Calculate a keyword match score.
- Generate AI-powered feedback and improvement suggestions.
- Identify relevant skills and missing requirements.
- Provide interview preparation suggestions.

Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- Google Gemini API

How to Run

1. Clone or download this repository.
2. Install the required Python packages.
3. Configure your Gemini API key securely using an environment variable.
4. Start the Flask backend.
5. Open the frontend in your browser.

Security

Never upload your ".env" file or API key to GitHub.

Project Goal

To help job seekers understand how well their resumes match job descriptions and identify ways to improve them.
